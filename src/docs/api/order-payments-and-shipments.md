# Orders (Overview)

This section has been split into:

- Orders: `api/orders.md` — place and read an order, cancel an unpaid one, and (staff) confirm, mark unavailable, or replace a line before it ships
- Payments: `api/payments.md` — start a payment and record a refund
- Shipments: `api/shipments.md` — read a parcel, and move the order when it is dispatched or delivered
